# TodoApp (using Riverpod)

A simple, well-structured Flutter todo app demonstrating state management with Riverpod. This project implements a clean, maintainable architecture for adding, editing, completing, and persisting todos — useful as a learning example or a small starting point for production apps.

## Features
- Add, edit, remove todos
- Mark todos as completed / uncompleted
- Filter todos (all / active / completed)
- Persistent storage (local)
- Clean separation of UI, state, and data layers
- Riverpod for predictable, testable state management

---

## Built with
- Flutter — UI toolkit
- flutter_riverpod — state management
- (Optional) Hive / SharedPreferences / SQLite — local persistence
- Dart — programming language
